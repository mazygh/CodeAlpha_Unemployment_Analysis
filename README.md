# Unemployment Analysis in India

## Overview
This project analyzes unemployment trends in India using real-world data to uncover patterns, trends, and the impact of Covid-19.

## Dataset
- Source: Kaggle
- Contains unemployment rates, employment data, and labor participation rates.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Seaborn

## Key Analysis
- Time-series analysis of unemployment rates
- Rural vs Urban comparison
- Impact of Covid-19
- Annual trend analysis

## Insights
- Urban areas are more affected by economic crises
- Covid-19 caused a significant rise in unemployment
- Long-term instability in labor markets is observed

## Limitations & Future Work
- Extend analysis with sectoral data
- Apply predictive models
- Add regional comparisons
